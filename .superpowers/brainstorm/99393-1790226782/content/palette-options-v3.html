暗色版 · 招牌渐变做点缀

DARK + APPICA ACCENTS

暖黑底 #161310 + 同款招牌渐变作为主按钮/进度条。兼顾暖色调 + 暗色基调 + Appica 视觉语言。运维 24 小时不刺眼，渐变又点睛。

Appica 的核心设计语言：
1. 招牌渐变 #8EC5FF → #EFADF7 → #FFD69B（蓝→粉→米黄），贯穿主按钮/进度条/装饰
2. 大圆角 14-24px，比 Linear (6px) 圆润很多，更亲和
3. 柔阴影 `0 1px 3px rgba(0,0,0,0.04)`，几乎"无"阴影但有立体感
4. 1px 细边框 #ECECEA（亮）/ #2A241E（暗），比 Naive UI 的 1px 更克制
5. 字重对比 标题 700 + 大字号 + letter-spacing 负值，比之前的 600 更"挺"
